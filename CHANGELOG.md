## [1.0.0] - Previous Version

### Features
- Face detection using DNN
- Face recognition with DeepFace
- Object detection using YOLOv4-tiny
- Real-time tracking
- Interactive face naming
- Persistent face database
- Unified detection mode
- Performance configuration

### Core Modules
- Face detector (ResNet-10 SSD)
- Object detector (YOLOv4-tiny)
- Face embedder (Facenet/VGG-Face)
- Face tracker (sample collection)
- Face database (persistent storage)
- UI renderer (visualization)
- Input handler (keyboard control)
